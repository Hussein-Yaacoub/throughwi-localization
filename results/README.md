# Results

[residential_baseline.json](residential_baseline.json) was generated by `python scripts/prepare_captures.py` followed by `python scripts/baseline.py --out results/residential_baseline.json`. This method predicts one position for every packet using the geometric median of the distinct training positions. Only the labels from the training split fit that position. The JSON includes test errors by recording.

The neural model figures from the FYP report are listed separately in the root README. Their associated checkpoints and original evaluation logs are pending recovery.
